배열 
- 연속적인 공간에 저장
- 각 요소는 인덱스에 저장, 인덱스는 0부터 시작
- 크기는 배열에 있는 요소의 개수

배열 선언 구조 ex)  int array[10];
int - 배열요소 자료형
array - 배열명
10 - 배열의 크기

배열 요소에 접근할 때는 인덱스 사용
int arr[3] = {1, 2, 3}

배열의 크기를 확인할 때는 sizeof 사용

int arraySize = sizeof(score) / sizeof(score[0]);  -> 배열 요소의 개수 구하기

int arrayBytes = arraySize * sizeof(int);  -> 배열의 용량 구하기

배열과 매개변수
- 배열의 모든 요소를 한꺼번에 함수에 전달 가능
- 배열명의 함수의 매개변수로 사용하면 배열의 모든 요소 전달
ex)  int x[]

버블 정렬 - 인접한 2개씩 비교해가며 오름차순으로 최대값을 맨 오른쪽 끝으로 정렬하는 방식
