선택 정렬 : 배열에서 가장 작은 값을 찾아서 현재 위치의 값과 교환하는 정렬 알고리즘

1. 배열에서 가장 작은 값을 찾는다.
2. 가장 앞의 값과 위치를 바꾼다.
3. 그다음 위치부터 다시 가장 작은 값을 찾는다.
4. 배열이 정렬될 때까지 반복한다.


삽입 정렬 : 배열의 원소를 하나씩 꺼내서 이미 정렬된 부분의 알맞은 위치에 삽입하는 정렬 방법
카드 게임에서 카드를 손에 하나씩 추가하면서 알맞은 위치에 끼워 넣는 것과 비슷.

포인터 :  데이터가 저장된 메모리의 주소를 지정하는 변수
- 메모리 주소는 보통 16진수
- 특정 주소에 1바이트 크기로 저장
- 메모리 할당이 순차적이지 않음

& : 포인터 주소 연산
scanf() 함수에서 사용한 &가 바로 주소 연산자
- & 연산자를 이용하면 변수의 메모리 주소 확인 가능

포인터 변수: 변수의 메모리 주소를 저장하는 변수
* : 포인터 간접연산자
- 선언하고 사용할 때 -> 참조하고 있는 메모리 주소의 값에 접근한다는 뜻
포인터 변수는 사이즈가 항상 8바이트

-함수와의 상호작용
 -> 매개변수로 메모리 주소 전달 가능
