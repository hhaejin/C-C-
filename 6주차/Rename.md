선택 정렬 : 배열에서 가장 작은 값을 찾아서 현재 위치의 값과 교환하는 정렬 알고리즘

1. 배열에서 가장 작은 값을 찾는다.
2. 가장 앞의 값과 위치를 바꾼다.
3. 그다음 위치부터 다시 가장 작은 값을 찾는다.
4. 배열이 정렬될 때까지 반복한다.


삽입 정렬 : 배열의 원소를 하나씩 꺼내서 이미 정렬된 부분의 알맞은 위치에 삽입하는 정렬 방법
카드 게임에서 카드를 손에 하나씩 추가하면서 알맞은 위치에 끼워 넣는 것과 비슷.

- 특정 주소에 1바이트 크기로 저장
- 메모리 할당이 순차적이지 않음
