포인터 변수 p가 가리키는 증가 표현식
 (*p)++ : 현재 값을 반환하고 이후 값을 증가시킴
 (*p)+1 : 값을 변경하지 않고 1만큼 더한 결과를 반환
 *p+=1 : 값을 1 증가시키고 결과 다시 저장
 (*p)+=1 : *p+=1과 동일
 *p=*p+1 : 값을 1 더하고 결과 저장
 ++*p : 값을 먼저 1 증가시키고 증가된 값 반환
 ++(*p) : ++*p와 동일하며, 연산 순서를 명확히 표현한 

 *(p++) - 주소 증가
 (*p)++ - 값 증가

 *p++ 연산 - *p와 p++의 결합과 같음. *(p++)과 같음
 - 후위 증가 연산자 사용으로 p의 증가는 *p가 지정된 후에 발생, p가 가리키는 값을 반환한 후에 p의 주소 증가

 - *++p연산 - ++p와 *p의 결합과 같음. *(++P)와 같음
 - 포인터 변수 p를 증가시킨 다음 증가된 p가 가리키는 값 반환
