파일의 구조
-데이터를 파일에 저장하고 관리하기 위해 먼저 파일의 구조 확인
-이름과 파일을 식별하는데 사용
파일 처리
-프로그램에서 파일을 연다는 것은 파일의 데이터를 읽고 쓸 수 있게 한다는 것
FILE구조체 - 파일을 다루기 위한 포인터 변수를 선언한 것 , 대문자로 시작
파일 열기 - fopen() 파일의 경로와 모드를 인자로 받음
r - 읽기전용모드, 파일 없으면 NULL 반환, w - 쓰기전용모드, 파일 없으면 새 파일 생성, 파일 있으면 기존 내용 모두 삭제 후 새로 시작,
파일 닫기 - fclose() 열린 파일과 관련된 모든 버퍼를 정리,파일에 대한 접근 종료
fgets() - 파일 포인터 fp가 가리키는 대상 파일에서 1바이트씩 읽어 int형으로 반환, 오류 발생하거나 파일의 끝을 만나면 EOF 반환
fputs() - 파일에서 문자열 단위로 출력을 수행하는 함수
fscanf() - 파일을 대상으로 서식화된 입력 기능을 지원하며, 파일에서 읽어들인 항목 수를 정수로 반환
fprintf() - 파일을 대상으로 서식화된 출력 기능을 지원하며, 파일에 저장된 바이트 수를 정수로 반환
